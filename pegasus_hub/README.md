# Pegasus Hub

Run Unfolded Circle **Remote 3 / Remote Two** integrations here in Home Assistant instead of on the remote. They show up on the remote as if they were installed there, and integrations you already installed on the remote can be moved here with one click, to get past the remote's 10-integration limit and spare its battery.

Install **Pegasus Bridge** on the remote to link it. See the Documentation tab.
